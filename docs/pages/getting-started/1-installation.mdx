# Installation
The recommended way to install Current is using [Rokit](https://github.com/rojo-rbx/rokit).
<Steps>

### Installing Current

Open a terminal in your project directory and run the following command:

```sh copy filename="Bash"
rokit add Acidgorgon/current
```

Or add this line under `[tools]` in your `rokit.toml`:

```toml copy filename="rokit.toml"
current = "Acidgorgon/current@0.1.0"
```

### Updating Current

When a new version of Current releases, using Rokit you can easily update using the following command:

```sh copy filename="Bash"
rokit update Acidgorgon/current
```

</Steps>

## Alternatives

<details>
<summary>GitHub Releases</summary>

You can download pre-built binaries directly from the
[GitHub Releases](https://github.com/Acidgorgon/current/releases) page.
Extract the archive for your platform and put the `current` executable (`current.exe` on Windows) on your `PATH`.

</details>

<details>
<summary>Roblox Studio</summary>
Current offers a companion studio plugin which allows you to write and generate files within Studio without the need for external tooling.  
Download `current-plugin.rbxm` from [GitHub Releases](https://github.com/Acidgorgon/current/releases) and put it in your Studio plugins folder.
</details>
